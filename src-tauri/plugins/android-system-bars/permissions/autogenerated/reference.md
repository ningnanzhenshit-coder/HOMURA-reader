## Default Permission

Allows HOMURA to match Android system bar icons with the reading surface.

#### This default permission set includes the following:

- `allow-setAppearance`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`android-system-bars:allow-setAppearance`

</td>
<td>

</td>
</tr>

<tr>
<td>

`android-system-bars:deny-setAppearance`

</td>

</tr>
