## Default Permission

Allows HOMURA to read CBZ/ZIP pages and EPUB document entries through the Android archive cache.

#### This default permission set includes the following:

- `allow-open`
- `allow-openDocument`
- `allow-readTextBatch`
- `allow-extract`
- `allow-close`
- `allow-clearBook`
- `allow-clearAll`
